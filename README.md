This is a GitHub repository to maintain our analysis files for comparing separate mediation models, multiple mediator models, and latent/summary mediator models when there are multiple indicators that can act as mediators of a relationship.

FTE (Forward Testing Effect) data set is shared as the main empirical example. The data and analysis scripts by the original research team are available via a preliminarily anonymized OSF link at https://osf.io/jyrq8/?view_only=ede69ce309484a40bc50904358e7abb7.

Please feel free to add other general notes here!
